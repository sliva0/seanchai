# History

Completed work registers. These are records of what was done and why, not
schedules — nothing here is outstanding. They are kept because the reasoning
behind a finished change is the expensive part to reconstruct, and because a
later review should be able to see what an earlier one already settled.

Current planned work lives in [roadmap.md](../roadmap.md).

  code-quality review's seven items, all implemented.
- [review-code-quality.md](review-code-quality.md) — the second review, taken
  at commit `6b5b9a6`. Its thirteen findings are implemented, except the switch
  from the `Specs/latest/Rel-N` index to the version-preserving 3GPP archive,
  which is a feature and is tracked in the roadmap.
